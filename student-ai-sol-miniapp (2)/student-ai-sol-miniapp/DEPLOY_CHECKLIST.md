# Student AI — запуск

1. Распакуй архив.
2. Открой `SETUP.ts` и заполни только его.
3. Установи Node.js 20+.
4. Запусти `start.bat` (Windows) или вручную `npm install` → `npm run dev`.
5. Для Telegram нужен публичный HTTPS URL.
6. В `SETUP.ts` замени `MINI_APP_URL` на этот HTTPS URL.
7. В @BotFather задай Main Mini App на этот URL.
8. Установи webhook на `https://ТВОЙ_ДОМЕН/api/telegram/webhook` с секретом из `SETUP.ts`.
9. Проверь `/start`, фото/текст, подтверждение условия и оплату Stars.
10. Проверь `/terms` и `/paysupport`.
