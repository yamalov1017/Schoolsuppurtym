# Student AI Mini App

Готовый MVP Telegram Mini App для решения школьных задач по **фото или тексту** на **GPT-6.1 Sol**.

## Важное: заполняется только один файл

После распаковки открой:

`SETUP.json`

Туда вставляются:
- `BOT_TOKEN` — токен бота от @BotFather;
- `BOT_USERNAME` — username бота без @;
- `OPENAI_API_KEY` — ключ OpenAI API;
- `MINI_APP_URL` — HTTPS-адрес опубликованного Mini App;
- `WEBHOOK_SECRET` — придумай сам длинную строку.

Для базового запуска остальные исходники менять не нужно.

## Что умеет

- задачи по тексту;
- задачи по фото;
- распознавание условия перед решением;
- вопрос «Я правильно понял задачу?»;
- решение только после подтверждения;
- подробные объяснения;
- предметы: математика, физика, химия, биология, информатика, русский, литература, английский, история, обществознание, география и другие;
- 3 бесплатных решения каждый день;
- 59 ⭐ — доступ к Sol на 7 дней;
- 149 ⭐ — доступ к Sol на 30 дней;
- база пользователей и покупок;
- Telegram Stars + pre-checkout + successful_payment;
- `/terms`, `/support`, `/paysupport`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

Для запуска из Telegram Mini App нужен публичный HTTPS URL. После деплоя поставь этот URL в `SETUP.json` и перезапусти приложение.

## Telegram webhook

После публикации Mini App webhook должен указывать на:

`https://ВАШ_ДОМЕН/api/telegram/webhook`

Установка webhook делается через Bot API с `secret_token`, который должен совпадать с `WEBHOOK_SECRET`.

## Платежи

Так как это цифровая услуга внутри Telegram, используется Telegram Stars (`XTR`).

- 59 ⭐ = 7 дней;
- 149 ⭐ = 30 дней.

Это разовые покупки доступа. Автопродления нет.

## Модель

Проект использует `gpt-6.1-sol`. OpenAI указывает для неё поддержку текста и изображений через Responses API.

Обрати внимание: модель не гарантирует 100% правильность каждой олимпиадной или нестандартной задачи.
